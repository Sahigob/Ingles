Tu profesor de inglés

Una IA que se ejecuta en tu navegador. Habla o escribe, recibe respuestas habladas y practica conversaciones adaptadas a B1 o B2.

Preparado para iniciar
Modelo local · Qwen 1.5B

Primera preparación

El profesor utiliza un modelo de IA gratuito que se descarga una vez en este navegador. La descarga inicial es de aproximadamente 1,6 GB. Después se reutiliza la copia en caché, si el navegador la conserva.

Necesitas Chrome o Edge actualizado y un dispositivo compatible con WebGPU.

Cuando el profesor esté listo, comenzará la conversación.

Pulsa «Hablar» y responde en inglés, o escribe tu respuesta.

Qué debes saber

  • Sin cuotas de IA: el modelo se ejecuta en el ordenador; no utiliza una API de pago.
  • Descarga inicial: aproximadamente 1,6 GB y requiere espacio y memoria gráfica suficientes.
  • Compatibilidad: requiere Chrome o Edge con WebGPU. Si el equipo no es compatible, no podrá cargar el profesor local.
  • Voz: utiliza el reconocimiento y la voz disponibles en el navegador. El reconocimiento de voz puede depender de servicios del navegador y no está garantizado en todos los equipos. También puedes escribir.
  • Privacidad: las respuestas se procesan localmente por el modelo. No se guardará el historial de esta conversación en Firebase.
